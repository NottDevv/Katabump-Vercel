# رلهٔ NotDev برای Vercel

این نسخه منطق `deno_relay_v9.js` را به Vercel Node.js Function منتقل می‌کند: انتخاب یکی از سرورها، پراکسی پنل، بازنویسی HTML و لینک‌های ساب، کوکی‌ها، مسیرهای `/admin/...`، انتخاب `core` و `/health`.

## استقرار

1. محتویات این پوشه را در یک مخزن Git جداگانه قرار دهید.
2. مخزن را در Vercel ایمپورت کنید؛ Framework Preset را روی **Other** بگذارید.
3. مطمئن شوید `api/relay.js` و `vercel.json` در ریشهٔ پروژه‌اند.
4. Deploy کنید.
5. تست سلامت: `https://YOUR-PROJECT.vercel.app/health`
6. پنل: `https://YOUR-PROJECT.vercel.app/configs?server=jabi83&user=Jabi83`

## تفاوت‌های محیطی مهم

- Vercel Functions دارای محدودیت زمان اجرا و اندازهٔ درخواست/پاسخ هستند؛ این محدودیت‌ها با Deno Deploy کاملاً یکسان نیستند.
- این رله تمام درخواست‌های پنل و پاسخ سابسکریپشن را از طریق Function عبور می‌دهد؛ صرفاً لینک‌ساز نیست.
- در صورت استفاده از مسیرهای POST و بدنه‌های بزرگ، رفتار را با پنل واقعی آزمایش کنید.
- مسیر `/health` فقط زنده بودن Function را بررسی می‌کند و دسترسی به سرور بالادستی را تأیید نمی‌کند.
- آدرس‌های سرورها همان مقادیر موجود در `deno_relay_v9.js` هستند؛ قبل از انتشار عمومی، دسترسی به پنل مدیریت را امن کنید.

## متغیرهای index.js

در برنامهٔ اصلی تنظیم کنید:

- `VERCEL_RELAY_BASE_URL=https://YOUR-PROJECT.vercel.app`
- `VERCEL_RELAY_SERVER_KEY=Jabi7` (یا کلید سرور موردنظر که در رله تعریف شده)

سپس برنامهٔ اصلی را مجدداً اجرا کنید. لینک پنل Vercel فقط وقتی هر دو مقدار پر باشند در کنسول چاپ می‌شود.
